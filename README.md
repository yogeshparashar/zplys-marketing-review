# ZPLYS — marketing review

Finished reels and posters for the social team. Open the site, enter the shared
access code, review, download.

**Site:** https://yogeshparashar.github.io/zplys-marketing-review/

## Uploading a new version

1. Open the asset folder in this repo and go to the product and section
   (`<slug>/auction/posters/`, `<slug>/auction/confessions/`, and so on).
2. **Add file → Upload files**, drop in a file with **exactly the same name**.
3. **Put your name in the commit message** — e.g. `Neha: new cut of c2-chai`.
   The site lists recent uploads with the name attached, so everyone can see
   who changed what.

Adding something *new* (rather than replacing) needs a rebuild before it shows
up in the index — open an issue and it will be picked up.

## What is here

Only finished deliverables. No source, no voice cache, no raw renders — this
repo is the output, not the factory.
